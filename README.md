# 자몽의 숲 · 다운로드

설치 파일과 앱 업데이트 목록만 공개하는 저장소입니다. 게임 소스, 개인 저장, 프로필 연결·복구 파일은 공개하지 않습니다.

[최신 릴리스](https://github.com/ste41th/jamong-releases/releases/latest)

- [Windows 설치 EXE 한 개](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.10/jamong-windows-setup-v10.exe)를 받아 설치한 뒤 시작 메뉴의 **자몽의 숲**을 실행하세요. 관리자 설치나 보안 설정 변경은 요구하지 않으며 설치 후 자동 실행하지 않습니다. ZIP은 앱 내부 업데이트용입니다.
- [Android APK](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.10/jamong-android-v10.apk)를 기존 Unity 버전 위에 업데이트 설치하세요. 기존 앱과 저장 데이터를 먼저 삭제하지 마세요. 기존 Godot 앱과는 다른 패키지입니다.
- 앱 시작 시 최신 버전을 비차단으로 확인합니다. 최신 버전·조회 실패는 작은 안내로 표시하고 새 버전의 다운로드·설치는 사용자가 확인합니다. 네트워크 오류로 게임 실행을 막지 않습니다.
- Windows 저장·프로필 연결 파일의 기존 경로를 유지합니다. 연결·복구 파일은 비밀번호처럼 보관하고 공개 저장소나 이슈에 올리지 마세요.

현재 dev.10은 UI/UX 패치 검증판입니다. 코드 132개·실제 장면 흐름 1개, 격리 설치/업데이트/실패 복구/제거 시 저장 보존 검사를 통과했습니다. 휴대폰 실기기·전체 시각적 UI·PC/휴대폰 실제 동시 플레이는 아직 검증하지 않았습니다. 전체 게임 이전 완료나 정식 출시를 의미하지 않습니다.

Windows 설치기는 코드 서명되지 않았으며 Android는 기존 Debug 서명을 유지합니다. 사용법과 파일 해시는 각 릴리스의 USER-GUIDE.txt와 SHA256SUMS.txt를 참고하세요.
