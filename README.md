# 자몽의 숲

공개 설치 파일 전용 저장소입니다. 개발 소스와 개인 저장·프로필 연결/복구 파일은 포함하지 않습니다.

## dev.13 다운로드

- [Windows 설치 EXE](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.13/jamong-windows-setup-v13.exe)
- [Android APK](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.13/jamong-android-v13.apk)
- [변경 내역과 검증 범위](https://github.com/ste41th/jamong-releases/releases/tag/v0.6.0-dev.13)

원본 타이틀 이미지를 복원했습니다. 재방문은 **이어하기**, 처음에는 이름 선택 후 온라인 입장입니다. 프로필 바꾸기는 별도로 유지하며 단일 섬의 중간 확인 화면을 제거했습니다.

기존 앱을 삭제하지 말고 APK/EXE로 업데이트하세요. 이번 변경은 실행 코드 수정이므로 데이터 패치만으로 적용되지 않습니다. 기존 패키지·서명·저장을 유지합니다. Windows 설치기는 미서명이며 설치 후 자동 실행하지 않습니다.

dev.12 이동 수정 및 온라인 프로토콜·세계 ID를 유지합니다. dev.12/dev.13 혼합 실접속은 미검증이며 양쪽 모두 dev.13 사용을 권장합니다. 휴대폰 시각 확인과 변경 입장 흐름의 실서비스 검증은 미실시입니다.

현재 이름 선택 접근 정책을 유지합니다. 공개 앱을 받은 다른 사람도 두 프로필을 선택할 수 있습니다. 관리자 권한이나 다른 DB 컬렉션의 공개를 의미하지 않습니다.

일반 사용자는 Windows ZIP을 직접 풀 필요가 없습니다. ZIP과 버전 목록·해시는 기존 업데이트 호환과 검증용이며 원격 실행 코드는 콘텐츠 패치에 포함하지 않습니다.
