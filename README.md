# 자몽의 숲

Windows·Android용 2인 온라인 생활 게임의 **설치 파일 공개 저장소**입니다. 게임 소스, 계정 자격증명, 개인 저장과 프로필 연결·복구 파일은 공개하지 않습니다.

## dev.15 다운로드

- [Windows 설치 EXE](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.15/jamong-windows-setup-v15.exe)
- [Android APK](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.15/jamong-android-v15.apk)
- [변경 사항과 검증 한계](https://github.com/ste41th/jamong-releases/releases/tag/v0.6.0-dev.15)
- [이전 dev.14 릴리스](https://github.com/ste41th/jamong-releases/releases/tag/v0.6.0-dev.14)

기존 앱 위에 업데이트하세요. 앱이나 저장을 삭제할 필요가 없습니다. Windows는 EXE 한 개로 설치하며 ZIP을 직접 풀 필요가 없습니다. 설치기는 **미서명**이며 설치 후 게임을 자동 실행하지 않습니다. Android는 OS의 정상 설치 확인을 따릅니다.

이번 버전은 기존 온라인 앱에 HLSL·해안 재질·Volume과 캐릭터 전시 후보를 연결한 **앱 코드 업데이트**입니다. 데이터 패치만으로 적용되지 않습니다. 콘텐츠 버전은 1을 유지하며 일반 게임 UI의 자동 APK/EXE 설치는 활성화돼 있지 않습니다. ZIP·버전 목록·해시는 업데이트 호환과 내부 검증용 보조 자료입니다.

원본 타이틀과 이름 선택·이어하기·온라인 입장, 기존 플레이어 이동·저장을 유지합니다. 함께 플레이할 두 기기를 dev.15로 맞추는 것을 권장합니다. 공개 이름 선택 접근 정책을 유지하므로 다른 다운로드 사용자도 두 프로필로 접속할 수 있습니다. 이것은 다른 데이터베이스 전체 공개를 의미하지 않습니다.

## 시각 개선 단계와 실제 상태

원본 아트와 캐릭터 정체성을 보존하며 일관된 생활 게임 화면을 목표로 합니다. 특정 작품의 공식 후속작이나 관계를 뜻하지 않으며 검사 통과를 시각 품질 완성으로 취급하지 않습니다.

| 단계 | 산출물 | 현재 상태 | 완료 기준 |
|---|---|---|---|
| 0 | 프로필 이름·원본 로고·간결한 입장 UI | 기존 수정 유지, PC 검토·입력 검사 완료; 새 휴대폰 화면 미검수 | 이름 식별, 중복 입력/취소/재시도와 실제 화면 확인 |
| 1 | 바닥·지형·바다·해안·조명·재질 | 전체 섬 해안 재질과 HLSL/Volume 연결; PC GPU 검토, PC/Android 빌드 | 수영/충돌·기존 세계 보존, 화면 검토와 폰 성능 확인 |
| 2 | 캐릭터 형태·색감·표정·동작 | 전시 후보 **10개**, 원작 충실도 검수 완료 **0개**; 새 리그는 전시만 | 캐릭터별 정면/측면/후면·동작 대조, 미확인 부위와 실패 후보 해결 |
| 3 | 식생·LOD·그림자 | 로컬 검토/비용 개선 후보, 미세 전환 튐 등 후속 검토 | 외형 보존·전환 안정성·실제 렌더 비용 확인 |
| 4 | 건물·가구 형태와 재질 | 기존 자산·출입/배치 유지, 재질 통합; 전반 품질 개선 미완료 | 소유권/수량/회전/충돌/저장 회귀 및 시각 일관성 |
| 5 | 전체 UI·VFX·카메라 일관성 | 기존 수정 유지, 전반 개선 미완료 | 화면비/안전 영역/입력 차단과 장면 간 일관성 |
| 6 | 모바일·온라인 통합 검증 | 이번 PC/Android 빌드 및 로컬 통합 검사; 새 실기기·두 기기 온라인 미실시 | 폰 프레임/메모리·조작·온라인 저장/재접속 확인 |

전시는 비거주·비동기화 장식이며 기존 주민·소유권·저장 스키마를 바꾸지 않습니다. 가구·건물과 겹치면 전시만 숨깁니다. 실패한 의상 접합 후보는 채택하지 않았습니다. 바다는 기존 해안 개선의 통합이며 이번에 새 바다를 완성했다는 의미가 아닙니다.

휴대폰 신규 설치·성능, 이번 Windows 설치기 실행, dev.15 두 기기 온라인·혼합 버전 플레이는 미검증입니다. dev.14를 보존하지만 OS의 낮은 버전 설치 제한 때문에 인플레이스 다운그레이드를 보장하지 않습니다. 저장을 삭제하지 마세요.
