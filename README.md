# 자몽의 숲

공개 설치 파일 전용 저장소입니다. 개발 소스와 개인 저장·프로필 연결/복구 파일은 포함하지 않습니다.

## dev.13 다운로드

- [Windows 설치 EXE](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.13/jamong-windows-setup-v13.exe)
- [Android APK](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.13/jamong-android-v13.apk)
- [변경 내역과 검증 범위](https://github.com/ste41th/jamong-releases/releases/tag/v0.6.0-dev.13)

원본 타이틀 이미지를 복원했습니다. 재방문은 **이어하기**, 처음에는 이름 선택 후 온라인 입장입니다. 프로필 바꾸기는 별도로 유지하며 단일 섬의 중간 확인 화면을 제거했습니다.

기존 앱을 삭제하지 말고 APK/EXE로 업데이트하세요. 이번 변경은 실행 코드 수정이므로 데이터 패치만으로 적용되지 않습니다. 기존 패키지·서명·저장을 유지합니다. Windows 설치기는 미서명이며 설치 후 자동 실행하지 않습니다.

dev.12 이동 수정 및 온라인 프로토콜·세계 ID를 유지합니다. dev.12/dev.13 혼합 실접속은 미검증이며 양쪽 모두 dev.13 사용을 권장합니다. 휴대폰 시각 확인과 변경 입장 흐름의 실서비스 검증은 미실시입니다.

현재 이름 선택 접근 정책을 유지합니다. 공개 앱을 받은 다른 사람도 두 프로필을 선택할 수 있습니다. 관리자 권한이나 다른 DB 컬렉션의 공개를 의미하지 않습니다.

일반 사용자는 Windows ZIP을 직접 풀 필요가 없습니다. ZIP과 버전 목록·해시는 기존 업데이트 호환과 검증용이며 원격 실행 코드는 콘텐츠 패치에 포함하지 않습니다.


## 시각 개선 단계 계획

목표는 기존 원본 아트와 캐릭터 정체성을 살린 일관된 cozy life-sim입니다. 특정 게임의 공식 후속작·관계를 뜻하지 않으며, 품질 목표를 이미 달성했다고 주장하지 않습니다. 현재 공개 앱은 dev.13이고 아래 작업은 별도 개발 중입니다.

| 단계 | 범위·산출물 | 현재 상태 | 완료 기준 |
|---|---|---|---|
| 0 | 프로필 이름 표시, 원본 로고 유지, 큰 로딩 카드·임시 아이콘 정리 | 로컬 수정·입력 검사 7개 통과, 시각 미검증 | 두 이름의 실제 문자 생성·중복 입력/취소/재시도 검사 + 화면 시각 확인 |
| 1 | 대표 해안의 바닥·지형, 바다·모래 경계, 조명·재질 통일 | 별도 해안 장면 구현·구조 검사 및 PC/Android 번들 컴파일 완료, 시각 미검증 | 수영/충돌 높이 보존, 메시·셰이더 비용 기록 + 대표 구간의 형태/경계/빛 시각 확인 |
| 2 | 캐릭터 비율·재질·표정·걷기/수영/상호작용 | 미착수 | 선택·소유권·외형 정체성 보존, 애니메이션 전이 검사 + 실제 움직임 시각 확인 |
| 3 | 식생의 형태·밀도·바람·그림자 | 미착수 | 가림/충돌/배치 및 렌더 비용 검사 + 해안과 동일한 스타일 확인 |
| 4 | 건물·가구의 형태·재질·배치 일관성 | 미착수 | 소유권·수량·회전·충돌·저장 회귀 검사 + 크기/디테일/재질 시각 확인 |
| 5 | 전체 UI·VFX·카메라 스타일 통일 | 미착수(시작 화면 회귀는 0단계 선행) | 안전 영역·가독성·입력 차단·가림 검사 + 장면 간 일관성 확인 |
| 6 | 모바일 최적화·시각/조작/온라인 통합 검증 | 미착수 | 실제 휴대폰 프레임 시간/메모리 측정, 두 클라이언트·저장/복원 검사 + 최종 시각 검토 |

색상 변경이나 자동 검사 통과만으로 시각 완성을 판정하지 않습니다. 모바일 30fps(프레임당 33.3ms)를 잠정 예산으로 삼되 실제 기기 측정 전 성능을 보장하지 않습니다. 현재 휴대폰의 신규 화면/대표 해안 시각 검증은 미실시입니다. 기존 이동 수정·온라인·저장과 원본 타이틀은 보존하며 새 앱/콘텐츠 배포는 별도 진행합니다.
