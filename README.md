# 자몽의 숲

Windows PC와 Android에서 두 사람이 함께 생활하는 온라인 게임입니다.

## 0.2 — 설치 빌드 19

프로필 선택 뒤 **“섬에 연결하지 못했어요”**가 표시되던 입장 오류를 수정했습니다. 집이나 이전 가구 정보가 없는 초기 상태를 읽는 처리를 고쳤으며, 관련 로컬 검사 **26개가 통과**했습니다. 실제 휴대폰에서의 입장과 두 기기 동시 플레이는 아직 확인하지 않았습니다.

표시 버전은 **0.2**, 설치 빌드는 **19**입니다. 이번 수정은 서버 규칙을 변경하거나 기존 플레이어를 다시 초기화하지 않습니다.

## 다운로드와 업데이트

| 기기 | 설치 파일 |
|---|---|
| Android | [jamong-android-v19.apk](https://github.com/ste41th/jamong-releases/releases/download/v0.2-build.19/jamong-android-v19.apk) |
| Windows PC | [jamong-windows-setup-v19.exe](https://github.com/ste41th/jamong-releases/releases/download/v0.2-build.19/jamong-windows-setup-v19.exe) |

**기존 앱을 삭제하지 말고 위 설치 파일을 직접 내려받아 업데이트 설치하세요.** 앱 안의 **새 소식 → 업데이트**는 콘텐츠 파일만 갱신하므로 이번 입장 오류 수정을 설치할 수 없습니다. 함께 플레이하는 두 기기 모두 설치 빌드 19로 업데이트하세요.

Windows 설치 프로그램은 서명되지 않아 게시자 확인 경고가 표시될 수 있습니다.

## 0.2에서 할 수 있는 일

- 신규 시작 시 **1,000코인**과 **도끼·곡괭이·호미·삽**을 받습니다.
- **400코인**으로 **10×10칸의 땅과 집**을 구매합니다. 플레이어당 집은 한 채이며, 첫 집 구매 때 기본 실내 가구 9개를 받습니다.
- 클릭이나 터치 한 번에 도끼를 한 번 휘두릅니다. 나무를 네 번 타격하면 그루터기와 주울 수 있는 통나무 1개가 남습니다.
- 자신의 가구를 회수하고 다시 배치합니다.
- 두 플레이어의 현재 캐릭터 선택은 서로 겹치지 않으며 NPC 후보에서도 제외됩니다. 오프라인 상태에서도 선택이 유지됩니다. 다른 모습으로 변경해도 기존 재산의 소유권은 유지됩니다.

## 저장 데이터

이번 설치 빌드 19는 기존 진행을 다시 초기화하지 않습니다. 앞선 0.2에서 **새 시작을 요청한 기존 플레이어만** 집·가구·재화·진행 기록을 초기화하고 신규 기본 지급을 적용했습니다. 다른 플레이어와 공용 섬 데이터는 유지했습니다.

## 아직 확인이 필요한 부분

Android의 분홍색 화면 문제에 대한 그래픽 설정 수정은 0.2에 포함되어 있으나, 실제 휴대폰에서 해결되었는지는 확인하지 않았습니다. 캐릭터 아트 후보 10개는 최종 품질 검수 전이며 기존 애니메이션을 사용합니다.
