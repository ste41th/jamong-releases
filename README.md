# 자몽의 숲

Windows PC와 Android에서 두 사람이 함께 생활하는 온라인 게임입니다.

## 0.2.0.1 · 설치 빌드 20

첫 시작 화면과 캐릭터 선택을 파스텔 UI로 정리했습니다. 새 키티 모델과 재질은 선택창과 실제 플레이에서 함께 사용하며, 가방은 아이콘 격자로 열고 도구를 장착하면 ‘장착 중’을 표시합니다. 개별 도끼질·도구 선택 버튼 대신 PC 좌클릭과 모바일 공통 사용 입력을 사용합니다.

| 기기 | 설치 파일 |
|---|---|
| Android | [APK 다운로드](https://github.com/ste41th/jamong-releases/releases/download/v0.2.0.1/jamong-android-v20.apk) |
| Windows PC | [설치 EXE 다운로드](https://github.com/ste41th/jamong-releases/releases/download/v0.2.0.1/jamong-windows-setup-v20.exe) |

**기존 앱을 삭제하지 않고 설치 파일을 직접 받아 업데이트하세요. 함께 플레이하는 두 기기를 모두 0.2.0.1로 맞춰야 합니다.** 이전 빌드와는 같은 온라인 방에 입장하지 않습니다. 앱 안의 ‘새 소식 → 업데이트’는 콘텐츠 전용이므로 이번 앱 변경은 설치되지 않습니다. Windows ZIP은 업데이트 구조용 부속 파일이며 일반 설치에는 EXE를 사용합니다.

Windows 설치 프로그램은 미서명이라 게시자 확인 경고가 표시될 수 있습니다. 설치기는 관리자 권한이나 게임 자동 실행을 요구하지 않습니다. 기존 패키지·Android 서명·저장 경로는 유지합니다.

## 콘텐츠와 저장

- 신규 플레이어 기본 지급은 1,000코인과 도끼·곡괭이·호미·삽입니다.
- 400코인으로 약 10×10칸의 땅과 집을 구매합니다. 플레이어당 집 한 채이며 첫 집 구매 때 기본 실내 가구 9개를 받습니다.
- 도끼 유효 타격 네 번으로 나무를 쓰러뜨리면 그루터기와 주울 수 있는 통나무 1개가 남습니다.
- 본인이 소유한 가구를 회수하고 다시 배치합니다.
- 두 프로필의 현재 캐릭터 선택은 서로 겹치지 않고 NPC 후보에서도 제외됩니다. 접속을 종료해도 선택은 유지됩니다. 외형 선택을 변경해도 기존 재산 소유권은 바뀌지 않습니다.
- 이번 업데이트는 기존 집·가구·재화·진행을 초기화하지 않고 운영 보안 규칙과 인증도 변경하지 않습니다.

## 검증과 남은 작업

이번 앱은 운영 V1 도구 저장 경로를 명시적으로 유지합니다. 미활성 V2 정책 조회 때문에 도구가 막히는 호환 문제를 수정했으며 최신 Unity 로컬 검사 222개와 V1 규칙 에뮬레이터 검사 57개를 통과했습니다. **V2 비동기 타격 저장은 활성화하지 않았으므로 서버 확정 대기는 남습니다.**

키티의 손·소매 연결, 일부 리본 형태와 야외 색감은 미완성입니다. 추가 미검수 형상·조명 실험은 제외했습니다. 캐릭터 후보를 원작 충실도 완성 모델로 평가하지 않았습니다. 이번 빌드의 실제 휴대폰 화면·성능과 두 기기 온라인 플레이는 아직 확인하지 않았습니다.
