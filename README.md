# 자몽의 숲

Windows PC와 Android에서 두 사람이 함께 생활하는 온라인 게임입니다.

## 0.2 업데이트

서버에 0.2 게임 규칙을 적용하고, 요청한 플레이어의 새 시작 처리와 서비스 활성화를 완료했습니다.

Android와 Windows 빌드가 완료됐습니다. 실제 휴대폰에서의 화면과 동작 확인은 남아 있습니다. 함께 접속하려면 **두 사람 모두 0.2로 업데이트**해야 합니다.

## 다운로드

| 기기 | 설치 파일 | 파일 크기 |
|---|---|---|
| Android | [jamong-android-v18.apk](https://github.com/ste41th/jamong-releases/releases/download/v0.2/jamong-android-v18.apk) | 81,472,367바이트 |
| Windows PC | [jamong-windows-setup-v18.exe](https://github.com/ste41th/jamong-releases/releases/download/v0.2/jamong-windows-setup-v18.exe) | 70,977,059바이트 |

표시 버전은 **0.2**, 설치 코드는 **18**입니다. 기존 앱 식별자와 Android 서명을 유지하는 업데이트입니다. Windows 설치 프로그램은 디지털 서명이 없어 게시자 확인 경고가 표시될 수 있습니다.

## 0.2에서 할 수 있는 일

- 신규 시작 시 **1,000코인**과 **도끼·곡괭이·호미·삽**을 받습니다.
- **400코인**으로 **10×10칸의 땅과 집**을 마련합니다. 플레이어당 집은 한 채이며, 첫 집 구매 시 기본 실내 가구 9개를 받습니다.
- 클릭이나 터치 한 번에 도끼를 한 번 휘두릅니다. 나무에 네 번 적중하면 그루터기와 주울 수 있는 통나무 1개가 남습니다.
- 자신이 소유한 가구를 회수하고 다시 배치합니다.
- 두 플레이어의 현재 캐릭터 선택은 서로 겹치지 않으며 NPC 후보에서도 제외됩니다. 접속을 종료해도 선택은 유지됩니다. 외형 선택과 집·가구의 소유권은 별도로 유지됩니다.

## 저장 데이터

기존 저장 데이터는 기본적으로 유지합니다. **새 시작을 요청한 기존 플레이어**의 집·가구·재화·진행 기록만 초기화하고 신규 기본 지급을 적용했습니다. 다른 플레이어와 공용 섬의 데이터는 유지했습니다.

## 현재 확인이 필요한 부분

Android의 모든 그래픽 품질 설정에 필요한 렌더링 구성을 적용해 분홍색 화면 문제의 원인을 수정했습니다. 실제 휴대폰에서 해결되었는지는 아직 확인하지 않았습니다.

작업 중인 캐릭터 아트 후보 10종은 모두 최종 품질 검수 전이며, 외형과 애니메이션을 계속 개선하고 있습니다. 이번 버전의 두 기기 온라인 플레이 검증도 남아 있습니다.
