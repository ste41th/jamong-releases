# 자몽의 숲

PC·Android 배포 파일 전용 저장소입니다. 소스·개인 저장·프로필 연결/복구 파일은 포함하지 않습니다.

- [Windows 설치 EXE](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.12/jamong-windows-setup-v12.exe)
- [Android APK](https://github.com/ste41th/jamong-releases/releases/download/v0.6.0-dev.12/jamong-android-v12.apk)
- [최신 버전과 사용 안내](https://github.com/ste41th/jamong-releases/releases/latest)

현재 dev.12입니다. 기존 앱을 먼저 삭제하지 말고 정상 설치 업데이트하세요. Windows 설치기는 미서명입니다. 설치 후 게임은 자동 실행하지 않습니다.

앱에서 오이호박이 또는 자몽잇을 선택해 서버 프로필을 불러옵니다. 이름만 선택하는 공개 정책이므로 앱을 받은 다른 사람도 해당 프로필로 접속할 수 있습니다. 자몽잇은 첫 접속 시 캐릭터를 직접 선택합니다.

dev.12 기반 앱 설치 이후 호환 에셋은 게임의 새 데이터 업데이트로 받습니다. 코드·엔진·SDK 변경은 기반 앱 업데이트가 필요합니다. 구 버전 호환용 ZIP은 일반 설치용이 아닙니다.

두 소프트웨어 클라이언트 및 실제 서버 검사를 수행했습니다. 실제 휴대폰 동시 플레이와 최종 시각 품질은 아직 검증하지 않았습니다.

## dev.12 이동 수정

두 기기를 모두 dev.12로 업데이트하세요. 이번 수정은 실행 코드 변경이므로 콘텐츠 내려받기만으로 적용되지 않습니다. dev.11과 dev.12는 서로 다른 온라인 방을 사용합니다. 기존 저장·패키지·서명을 유지합니다. 휴대폰 실측과 새 두 클라이언트 검사는 미검증이며, 현재 플레이 세션을 교체하지 않았습니다.
