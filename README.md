# 자몽의 숲 · 다운로드

PC와 Android용 Unity 검증 빌드 및 업데이트 목록만 배포하는 저장소입니다. 게임 소스, 개인 저장과 프로필 연결·복구 파일은 포함하지 않습니다.

[최신 다운로드](https://github.com/ste41th/jamong-releases/releases/latest)

- Windows: ZIP을 쓰기 가능한 폴더에 풀고 Start-Jamong.cmd 실행. 스크립트 실행이 차단되면 versions 폴더의 Jamong.exe를 직접 실행하세요. 보안 설정 변경이나 관리자 실행은 필요하지 않습니다.
- Android: 동일 서명의 Unity 앱은 새 APK로 업데이트하세요. 기존 앱이나 저장 데이터를 삭제하지 마세요. 기존 Godot 앱과는 별도 패키지입니다.
- dev.8부터 앱 시작 시 최신 버전을 확인합니다. 네트워크 오류가 게임 실행을 막지 않습니다. 다운로드·설치는 사용자가 확인합니다. Windows는 이전 버전 폴더를 보존하고 Android는 정상 시스템 설치 확인을 사용합니다.

이 버전은 검증판입니다. 휴대폰 설치·터치·성능, Windows 그래픽 실행 및 두 실기기 플레이는 아직 검증하지 않았습니다. 전체 게임 이전 완료판이나 상시 서버가 아닙니다.

프로필 연결/복구 파일은 비밀번호처럼 보관하고 이 저장소·이슈·공개 링크에 올리지 마세요. Android 빌드는 기존 검증용 서명을 유지하며 Windows는 코드서명 없는 빌드입니다.
